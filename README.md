## Purpose
The primary objective of this repository is to maintain a consistent record of daily coding challenges, 
feature implementations, and bug resolutions. It facilitates self-reflection, tracks progress in key technologies, 
and provides a searchable archive for future reference or portfolio demonstration.

## Folder Structure
Folders are organized chronologically using the `DDMMYYYY_Day` format for easy navigation and historical tracking.

**Examples:**
- `31032026_tuesday/` - Work from Tuesday, March 31, 2026 (e.g., middleware implementations).
- `30032026_monday/` - Work from Monday, March 30, 2026 (e.g., LangChain memory practices).
- `27032026_friday/` - Work from Friday, March 27, 2026 (e.g., LangChain tools).

## Overview of Topics
This repository covers a broad range of topics explored during the internship, including:
- **Web Development:** Building APIs and web applications with Flask and FastAPI.
- **Machine Learning & Data Science:** Classification, regression, and clustering using Scikit-learn, Pandas, NumPy, 
and visualization with Matplotlib/Seaborn.
- **Deep Learning:** Neural network implementations with TensorFlow/Keras (e.g., CNNs, LSTMs, RNNs, and Transformers).
- **Databases:** CRUD operations with SQLAlchemy, PyODBC, PyMongo, and ChromaDB for vector storage.
- **Web Scraping & Automation:** Data extraction using BeautifulSoup and Selenium.
- **AI & NLP:** Agent-based systems and RAG (Retrieval-Augmented Generation) with LangChain.
- **Miscellaneous:** Custom middlewares, linear/logistic regression, and decision tree models.

Each folder contains focused implementations, datasets, and notes for quick reference.

## Prerequisites
To explore or run the code in this repository:
- Python 3.8+ installed.
- Required libraries can be installed via Poetry: `poetry install`.
- For database-related scripts: Ensure local instances of SQL Server, MongoDB, or other databases are running.
- For Selenium: Chrome browser and Chromedriver must be available.

## Usage
1. Clone the repository: `git clone <repository-url>`.
2. Navigate to a specific folder (e.g., `cd 31032026_tuesday/`).
3. Run scripts as needed (e.g., `python main.py`).
4. For web apps, start servers (e.g., `flask run` or `uvicorn app:app --reload`).

Note: This is a practice repository; scripts may require adjustments for production use.
